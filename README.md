# TrueNorthZen

TrueNorthZen is an Android application built with Kotlin and Jetpack Compose.

## Getting Started

This project uses Gradle as its build system.

### Prerequisites

- JDK 11 or higher
- Android SDK

### Building the Project

To build the project, run:

```bash
./gradlew assembleDebug
```

### Running Tests

To run unit tests, run:

```bash
./gradlew test
```
